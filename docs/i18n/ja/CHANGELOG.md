# 変更履歴

既存バージョンの記録です。正確なパッケージはソースの作業コピーと受け入れたビルド記録で識別します。

<a name="11--2026-11-10"></a>

## 1.1 — 2026 年 11 月 10 日

<a name="added"></a>

### 追加

- 最初の activate または bind-active-goal の試行を永続化。安全な再試行にパッケージ外で保持した失敗の SHA-256 を使用。
- candidate のライフサイクルを所有者が明確な単一ライターのロックで保護。
- tooling/run-lifecycle-check.py で準備、起動、新観測、停止後の再開、通常終了を支援。
- 明示的な timed-test で、SAVE、チェックポイント、halt の時刻を分け、遅いイベントを判定。ネイティブの一時停止は証明しない。
- 状態に実測時刻、期限、間隔、早期更新の目安を表示。
- 目的、構成、ワークフローと調整図、手動・エージェント経由の導入、ライフサイクルガイドを追加。

<a name="fixed"></a>

### 修正

- 使用量の証拠が期限切れの場合、同じ許可済み有効目標の下で条件付き復旧を実施。枠の枯渇やユーザー停止は対象外。
- 初回起動失敗後の再試行は、範囲、以前の SAVE、パッケージ紐付け、プロセス不在の検証を維持。
- 期間限定の週枠例外をコアと監視で揃え、観測値は書き換えない。
- Windows の特定の一時共有エラー・読み取りロックを有限回で再試行。継続する障害や不明なエラーは報告。
- 測定更新、リース延長、停止後の鮮度の条件を明確化。
- 旧テスト用関数の引数とファイル・プロセス待機を修正。

<a name="compatibility-and-evidence"></a>

### 互換性と証拠

- 呼び出し、導入ディレクトリ、新規実行領域をまとめて 1.1 へ移行。`$agent-workflow-v1-1`、`agent-workflow-v1-1/`、`.agent-workflow-v1-1/runs/`。
- 新マニフェストは旧識別子を拒否。旧実行は履歴として残し、新パッケージに自動で結び付けない。旧領域は担当と復元用に予約。
- 更新で不変の実行紐付けを改変しない。受け入れた更新で新しい実行を始める。
- Python 3.11+ と標準ライブラリ。監視はネイティブツールに直接アクセスせず、別の Codex サーバーを起動しない。
- 隔離試験は合成ホスト観測と実 Python プロセスを使用。実環境の Remote、Continue、画面操作と計時は別の証拠が必要。
- ソースコミットでバージョンを記録。当時の公開に GitHub Release やタグは含まれない。
