# Memoria del coordinatore

Questa memoria raccoglie le osservazioni verificate che il ruolo può riutilizzare.

Non è ancora stata registrata alcuna osservazione ricavata da un’attività. Per ogni futura voce indica progetto, riscontri e data. Le voci non conferiscono autorizzazioni e non prevalgono sulle istruzioni attuali.
