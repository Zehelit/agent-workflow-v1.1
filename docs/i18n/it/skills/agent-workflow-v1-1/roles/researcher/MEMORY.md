# Memoria del ricercatore

Questa memoria raccoglie le osservazioni verificate che il ruolo può riutilizzare.

Non è ancora stata registrata alcuna osservazione ricavata da un’attività. Per ogni futura voce indica progetto, riscontri e data. Controlla l’attualità dei risultati datati. Non conferiscono autorizzazioni e non prevalgono sulle istruzioni attuali.
