# Memoria dell’implementatore

Questa memoria raccoglie le osservazioni verificate che il ruolo può riutilizzare.

Non è ancora stata registrata alcuna osservazione ricavata da un’attività. Per ogni futura voce indica progetto, ambito specialistico, riscontri e data. Le voci non conferiscono autorizzazioni e non prevalgono sulle istruzioni attuali.
