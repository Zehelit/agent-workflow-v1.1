# Memoria del revisore

Questa memoria raccoglie le osservazioni verificate che il ruolo può riutilizzare.

Non è ancora stata registrata alcuna osservazione ricavata da un’attività. Per ogni futura voce indica progetto, riscontri e data. Le voci non sostituiscono l’esame degli elementi attualmente in revisione e non conferiscono autorizzazioni.
