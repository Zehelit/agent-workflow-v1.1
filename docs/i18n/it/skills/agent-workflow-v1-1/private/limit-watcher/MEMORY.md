# Memoria del ruolo di monitoraggio

Questa memoria raccoglie osservazioni verificate e riutilizzabili sulle misurazioni ambigue e sulla verifica della ripresa.

Non è ancora stata registrata alcuna osservazione ricavata da un’attività. Per ogni futura voce indica riscontri e data. Percentuali, orari di azzeramento, PID e identità di esecuzione storici non valgono mai come misura attuale o permesso di riprendere.
