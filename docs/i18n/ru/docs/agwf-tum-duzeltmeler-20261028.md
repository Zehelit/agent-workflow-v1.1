# Сопровождение мониторинга AGWF 28 октября 2026 г.

> Исторический отчёт о продолжении [первого этапа](agwf-duzeltmeler-20261028.md). Он не даёт разрешения активировать AGWF сейчас.

| Наблюдение | Изменение и зафиксированная тогда проверка |
| --- | --- |
| Шесть ролевых навыков могли выбираться автоматически | Каждая роль получила собственную настройку `allow_implicit_invocation: false` и ограничение подготовленными заданиями. Тесты пакета проверили все семь навыков. |
| Исходники, удалённый репозиторий и установка расходились | Инструменты включили в пакет. Установленные файлы сравнили с манифестом и ZIP из чистого исходного коммита. |
| В Windows конфликтовали чтение и запись | В соответствующих компонентах обновили совместное чтение и замену. Тесты временных файлов охватили блокировки, повтор и сохранение прежнего содержимого. |
| Для каждого замера запускался второй сервер Codex | Этот код удалили. Главный агент читает данные штатным инструментом среды, Python читает квитанцию. Тесты замера блокируют запуск процессов. |
| PATH мог выбрать другую CLI Codex | Выбор исполняемого файла удалили из пути замера. |
| Вывод ошибок отбрасывался | Дочерний сервер убрали. Ошибки замера сохраняют до 20 записей с кодом диагностики, классом и этапом. При непредвиденных сбоях процесса Python остаётся его локальный stderr. |
| Два цикла проверяли весь пакет каждую секунду | Сигнал активности проверяет только идентичность запуска и эпохи. Полная проверка выполняется при командах и замерах. |
| Тесты использовали имитацию сервера | Тесты перешли на формат квитанций расхода. В отчёте также зафиксирована проверка реального ответа Codex через временный файл. |
| В правилах роли сохранился ошибочный порог | Старый текст `%10` заменили на фактический порог остановки `%20`. При отказе запуска из-за отсутствия данных его отметка активности очищается. |

Данные передаются с исходным временем наблюдения и идентификатором источника через `--usage-input`. Монитор связывает квитанцию с запуском и эпохой. Отсутствующие, будущие, просроченные, более ранние или относящиеся к другому запуску замеры отклоняются. Повторная публикация замера не меняет время наблюдения. Без актуальных данных монитор повторяет проверку и затем фиксирует SAVE_AND_STOP.

Главный агент собирает новые наблюдения до срока. Python не вызывает инструмент среды. `ingest` лишь публикует данные. Активация, запуск процесса, разрешение, обновление наблюдения цели и снятие остановки остаются отдельными операциями.

Отчёт приводит 111 целевых тестов в обычном режиме и с `-O`. Настоящие запуски AGWF или Codex в этой серии блокировались. Сборщик пакета и тесты инструментов только для чтения могли использовать разрешённые дочерние процессы. Проверки исходников, хешей установки, выключенных настроек навыков и воспроизведения из чистого исходника фиксировались отдельно.

В отчёте также отмечено, что реальный результат замера среды прошёл по этому пути без запуска другого процесса и без изменения времени наблюдения. В пакет не добавляли данные учётной записи или личности. Точная причина исторической проблемы Remote осталась непроверенной. Одновременная работа AGWF и Remote не входила в тест. См. [формат штатных квитанций расхода](../skills/agent-workflow-v1-1/references/native-usage.md).
