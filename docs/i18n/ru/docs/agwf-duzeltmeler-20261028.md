# Сопровождение AGWF 28 октября 2026 г.

> Исторический отчёт о сопровождении. Приведённые наблюдения и разрешения относятся к тем работам. Текущий порядок работы описан в [README](../README.md).

Для каждого из шести навыков ролей добавили собственный `agents/openai.yaml` с `allow_implicit_invocation: false`. Описания ролей относятся к подготовленным заданиям AGWF. Роль останавливается без задания и подтверждений фактической модели и уровня рассуждения. Ролевые навыки не запускают рабочий процесс и монитор. Из основного навыка убрали формулировку, подразумевавшую, что выбор прежнего проекта продолжает действовать.

Исходники и установленную версию согласовали в части совместного чтения, замены с сохранением прав и ограниченных повторов для файлов состояния Windows. `candidate.py` читает изменяющиеся файлы состояния с тем же режимом совместного доступа. Если внешний читатель держит блокировку, старый файл сохраняется. Постоянная блокировка остаётся ошибкой.

Инструменты контекста и замеров переместили в `tools/` внутри пакета, чтобы пользовательская установка не зависела от рабочей копии проекта. В этой исторической проверке исходники, пакет и установка совпали по 41 файлу. Старую копию средства контекста из корня убрали, пути тестов обновили.

Отчёт приводит 63 теста пакета и инструментов и девять тестов доступа к файлам под Windows. Девять тестов Windows также выполняли с `-O` на установленных файлах. Проверили семь определений навыков и хеши файлов. Тест на шесть отсутствовавших правил ролей до исправления падал, после исправления прошёл.

Во время сопровождения AGWF был выключен. Все семь навыков остались выключенными. Тесты проверяли файловый доступ ядра на временных файлах. Совместную работу с Remote на действующей системе не проверяли.

Среди остававшихся тогда рисков были запуск второго сервера Codex на каждом замере, выбор другой CLI из PATH, потеря stderr дочернего сервера и повторная полная проверка пакета. Первый этап не установил причину сбоя Remote. [Продолжение работ](agwf-tum-duzeltmeler-20261028.md) описывает последующие изменения. Текущий монитор больше не запускает второй сервер Codex.
