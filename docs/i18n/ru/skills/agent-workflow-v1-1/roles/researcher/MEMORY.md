# Память исследователя

В этой памяти хранятся проверенные наблюдения, которые можно использовать в следующих задачах роли.

Наблюдения по задачам ещё не записывались. В будущих записях указывайте проект, подтверждения и дату. Давние выводы проверяйте на актуальность. Записи не дают разрешения и не отменяют текущие инструкции.
