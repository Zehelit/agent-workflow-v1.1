# Память роли мониторинга

Здесь хранятся проверенные наблюдения по неоднозначным замерам и проверке возобновления работы, которые можно использовать повторно.

Наблюдения по задачам ещё не записывались. В будущих записях указывайте подтверждение и дату. Старые проценты, время сброса, PID и идентификаторы запусков не являются ни текущими замерами, ни разрешением возобновиться.
