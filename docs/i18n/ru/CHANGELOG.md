# История изменений

Здесь приведены сведения об уже существующих версиях. Точный пакет определяется исходным коммитом и принятой квитанцией сборки.

<a name="11--2026-11-10"></a>

## 1.1 — 10 ноября 2026 г.

<a name="added"></a>

### Добавлено

- Постоянная запись о первой попытке activate или bind-active-goal. Для безопасного повтора используется SHA-256 квитанции ошибки, отдельно сохранённой за пределами пакета.
- Общая блокировка операций жизненного цикла кандидата, которой владеет запуск и в которой допускается один писатель.
- tooling/run-lifecycle-check.py для подготовки, запуска, обновления наблюдений, возобновления после остановки и нормального завершения.
- Явный режим timed-test с отдельными отметками времени для SAVE, контрольной точки и остановки, а также классификацией запоздалых событий. Инструмент не подтверждает паузу на стороне Codex.
- В сводках состояния — фактическое время замера, срок, интервал и рекомендуемое время обновления с запасом.
- Описание назначения, схемы архитектуры, рабочего процесса и оркестрации, инструкции по установке вручную и через агента, руководство по жизненному циклу.

<a name="fixed"></a>

### Исправлено

- Проверяемое возобновление после истечения срока замера в рамках той же разрешённой и активной цели. Для исчерпанной квоты и остановки пользователем действуют свои процедуры.
- Повтор после неудачного первого запуска сохраняет объём работы, предыдущие подтверждения SAVE и привязку к пакету. Отсутствие процесса проверяется.
- Ограниченное по времени исключение для недельного окна одинаково действует в ядре и мониторе. Наблюдавшиеся значения не переписываются.
- Ограниченные повторы обрабатывают распознанные временные ошибки совместного доступа Windows и чтения блокировок. Постоянные и неклассифицированные ошибки остаются видимыми.
- Уточнены обновление замера, продление срока работы и требования к актуальности данных после остановки.
- Обновлены сигнатуры старых вспомогательных функций тестов и ожидание процессов и файлов.

<a name="compatibility-and-evidence"></a>

### Совместимость и подтверждения

- Имя вызова, каталог установки и пространство состояния переходят на 1.1 вместе: `$agent-workflow-v1-1`, `agent-workflow-v1-1/` и `.agent-workflow-v1-1/runs/`.
- Новые манифесты отклоняют прежнюю техническую идентичность. Ранние запуски остаются историческими и автоматически не перепривязываются. Их пространства имён резервируются для проверки принадлежности и восстановления.
- Обновление не меняет неизменяемую привязку прежнего запуска. После одобрения нового пакета откройте новый запуск.
- Требуются Python 3.11 или новее и только стандартная библиотека. Монитор самостоятельно не обращается к штатным инструментам расхода и не создаёт второй сервер Codex.
- Изолированные тесты используют синтетические наблюдения среды и реальные процессы Python. Для работы Remote, Continue и времени реакции интерфейса нужны отдельные подтверждения.
- Версия зафиксирована коммитами исходного кода. Релиз GitHub и тег выходили за рамки зафиксированной публикации.

<a name="10--previous-source-version"></a>

## 1.0 — предыдущая версия исходников

- Точка входа кандидата с проверкой манифеста по хешу, типизированное состояние, документы ролей и проверки прав записи и вместимости.
- Встроенный монитор без модели, контрольные точки и восстановление, постоянный журнал координации и детерминированная сборка пакета.
- Историческая запись не утверждает, что существует соответствующий релиз GitHub или тег.
