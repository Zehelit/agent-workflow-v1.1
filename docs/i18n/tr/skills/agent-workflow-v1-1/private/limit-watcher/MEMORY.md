# Limit izleyicisi belleği

Kapsam ölçüm belirsizliği ve kurtarma doğrulamasına ilişkin yeniden kullanılabilir, doğrulanmış gözlemlerdir.

Görevlerden elde edilmiş gözlem henüz kaydedilmedi. Gelecek kayıtlar kanıtı ve tarihi içermelidir. Eski yüzdeler, reset zamanları, PID’ler ve run kimlikleri güncel ölçüm ya da devam yetkisi değildir.
