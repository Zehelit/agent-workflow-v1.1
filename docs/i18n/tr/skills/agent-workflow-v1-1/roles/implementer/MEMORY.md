# Uygulayıcı rolü belleği

Kapsam, uygulayıcı rolünde yeniden kullanılabilen doğrulanmış gözlemlerdir.

Görevlerden elde edilmiş gözlem henüz kaydedilmedi. Yeni kayıtlar proje ile uzmanlık alanını, kanıt ve tarih içermelidir. Kayıt çalışma yetkisi vermez veya güncel talimatları değiştirmez.
