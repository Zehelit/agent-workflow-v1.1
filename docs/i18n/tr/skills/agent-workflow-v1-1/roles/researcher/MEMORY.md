# Araştırmacı rolü belleği

Kapsam, araştırmacı rolünde yeniden kullanılabilen doğrulanmış gözlemlerdir.

Görevlerden elde edilmiş gözlem henüz kaydedilmedi. Yeni kayıtlar proje, kanıt ve tarih içermelidir. Tarihli bulguları güncellik açısından denetleyin. Bu kayıtlar çalışma yetkisi vermez veya güncel talimatları değiştirmez.
