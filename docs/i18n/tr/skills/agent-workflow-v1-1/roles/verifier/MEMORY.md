# Doğrulayıcı rolü belleği

Kapsam, doğrulayıcı rolünde yeniden kullanılabilen doğrulanmış gözlemlerdir.

Görevlerden elde edilmiş gözlem henüz kaydedilmedi. Yeni kayıtlar proje, kanıt ve tarih içermelidir. Kayıt güncel inceleme hedefini doğrulamanın yerine geçmez veya yetki vermez.
