# Mimar rolü belleği

Kapsam, mimar rolünde yeniden kullanılabilen doğrulanmış gözlemlerdir.

Görevlerden elde edilmiş gözlem henüz kaydedilmedi. Yeni kayıtlar proje, kanıt ve tarih içermelidir. Kayıt çalışma yetkisi vermez veya güncel talimatları değiştirmez.
