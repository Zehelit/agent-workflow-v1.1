# Mémoire du vérificateur

Cette mémoire rassemble les observations vérifiées que le rôle peut réutiliser.

Aucune observation issue d’une tâche n’a encore été consignée. Chaque future entrée doit indiquer le projet, les preuves et la date. Ces entrées ne dispensent pas d’examiner les cibles de la revue actuelle et n’accordent aucune autorisation.
