# Mémoire du coordinateur

Cette mémoire rassemble les observations vérifiées que le rôle peut réutiliser.

Aucune observation issue d’une tâche n’a encore été consignée. Chaque future entrée doit indiquer le projet, les preuves et la date. Ces entrées n’accordent aucune autorisation et ne priment pas sur les consignes en vigueur.
