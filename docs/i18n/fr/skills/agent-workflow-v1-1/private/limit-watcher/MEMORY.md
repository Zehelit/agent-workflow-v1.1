# Mémoire du moniteur d’utilisation

Cette mémoire rassemble les observations vérifiées et réutilisables sur les mesures ambiguës et les contrôles de reprise.

Aucune observation issue d’une tâche n’a encore été consignée. Chaque future entrée doit indiquer les preuves et la date. Les pourcentages, dates de réinitialisation, PID et identités d’exécution historiques ne valent ni mesure actuelle ni autorisation de reprendre.
