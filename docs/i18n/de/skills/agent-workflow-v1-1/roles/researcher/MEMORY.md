# Gedächtnis des Rechercheurs

Diese Datei sammelt wiederverwendbare, überprüfte Beobachtungen für die Rolle.

Aus Aufgaben sind bisher keine Beobachtungen dokumentiert. Künftige Einträge nennen Projekt, Nachweis und Datum. Prüfe bei älteren Erkenntnissen erneut die Aktualität. Sie erteilen keine Freigabe und ändern keine geltenden Anweisungen.
