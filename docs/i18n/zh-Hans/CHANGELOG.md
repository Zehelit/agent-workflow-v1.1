# 更新记录

这是现有版本历史。具体包内容由源工作副本和认可的构建回执确定。

<a name="11--2026-11-10"></a>

## 1.1 — 2026 年 11 月 10 日

<a name="added"></a>

### 新增

- 保存首次 activate 或 bind-active-goal 尝试的持久记录。安全重试使用包外保留的失败回执 SHA-256。
- candidate 生命周期操作使用归属明确的单写入者锁。
- tooling/run-lifecycle-check.py 支持准备、启动、刷新观测、停止后继续和正常关闭。
- 显式 timed-test 模式分别记录 SAVE、检查点和停止时间，并标出迟到的事件。工具不提供原生暂停证明。
- 状态摘要显示实际测量时间、期限、间隔和建议的提前刷新时间。
- 增加项目目的、架构、工作流和编排图、手动与代理安装说明及生命周期指南。

<a name="fixed"></a>

### 修复

- 用量证据过期时可在同一个已授权、仍活动的目标下做受控恢复。额度用尽和用户停止不走此路径。
- 首次启动失败后的重试保留范围、历史 SAVE、包绑定和进程已退出的证据。
- 有时限的周窗口例外在核心与监视器中一致生效，不会改写观测值。
- Windows 的暂时共享与读锁错误按已识别范围有限重试，永久与未知错误依然可见。
- 澄清刷新、续租和停止后观测的新鲜度要求。
- 更新旧测试辅助函数的签名以及进程和文件等待方式。

<a name="compatibility-and-evidence"></a>

### 兼容性与证据

- 调用、安装目录与新运行空间同步切换到 1.1：`$agent-workflow-v1-1`、`agent-workflow-v1-1/` 与 `.agent-workflow-v1-1/runs/`。
- 新清单拒绝旧技术标识。旧运行作为历史证据保留，不会自动绑定到新包。旧运行空间仍保留给归属与恢复。
- 包更新不改写已有运行的不可变绑定。接受新包后使用新运行 ID。
- 需要 Python 3.11+ 和标准库。监视器无法自行访问原生用量工具，也不启动第二个 Codex 服务。
- 隔离测试使用合成宿主观测和真实 Python 进程。实时 Remote、Continue 和界面计时需要各自的证据。
- 该版本通过源提交记录。原发布范围不含 GitHub Release 或标签。
