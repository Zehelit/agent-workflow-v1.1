> 历史维护记录。本文续接[首次维护](agwf-duzeltmeler-20261028.md)，不为当前运行提供启动授权。

用 `--usage-input` 传入原观测时间与来源身份。监视器将回执绑定到运行和轮次。重读文件不会生成新测量。缺失、未来、过期、倒退或其他运行的记录均拒绝。重复发布无法刷新时间。没有新观测则重试一次，随后记录 SAVE_AND_STOP。

主代理必须在期限前取得新观测。Python 不能调用宿主工具。`ingest` 只发布数据。激活工作流、启动进程、授权、刷新原生目标与清除停止状态均为其他操作。

记录报告普通和 `-O` 下的 111 个重点测试。测试阻止真实 AGWF 或 Codex 启动，允许构建与只读工具使用限定的子进程。源码测试、安装哈希、禁用设置和干净来源复现分别检查。

该次维护还记录了一条真实宿主用量回执通过新路径。保留原观测时间，未启动新进程，未把账户或身份信息加入软件包。历史 Remote 问题的确切原因仍未证实，实时 AGWF 与 Remote 共存不在该测试内。参见[原生用量约定](../skills/agent-workflow-v1-1/references/native-usage.md)。
